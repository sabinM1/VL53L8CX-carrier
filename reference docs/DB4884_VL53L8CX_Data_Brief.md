# DB4884 — VL53L8CX data brief

**Overview**
A summary brief highlighting the VL53L8CX capabilities: 60Hz framerate, 400cm range, low-power autonomous mode, and SPI/I2C connectivity for SLAM, gesture recognition, and laser-assisted autofocus (LAF).
