# TN1532 — dToF assembly recommendations

**1. Recommendations**
Guidelines for assembling dToF sensors without liners to maintain cleanliness and prevent particle deposition in critical optical areas. 
- Mount in a class 1000 environment.
- Use dry cleaning methods; avoid wet cleaning or coating.
