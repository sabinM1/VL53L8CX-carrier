## Part Number System
Example structure:
`MC A S 06 3 S B 7101 [F] C A01`

| Field | Meaning |
|---|---|
| (1) Series | MC = multilayer ceramic capacitor; MCAS/MCAR/MCJC/MCRL for automotive |
| (2) Category | C = automotive body/chassis/infotainment, quality grade 2 |
| (3) Rated voltage | A=4 V, J=6.3 V, L=10 V, E=16 V, T=25 V, G=35 V, U=50 V, H=100 V, Q=250 V, S=630 V |
| (4) Dimension | 06=0.6×0.3, 10=1.0×0.5, 16=1.6×0.8, 21=2.0×1.25, 31=3.2×1.6, 32=3.2×2.5, 45=4.5×3.2 |
| (5) Type | A = 2 terminals; J = soft termination; R = LW reversal |
| (6) Features | S = standard; R = high frequency/low loss; C = internal soft termination; L = low ESL |
| (7) Thickness | 3=0.3 mm, 5=0.5 mm, 7=0.7 mm, 8=0.8 mm, 9=0.85 mm, Q=1.15 mm, G=1.25 mm, L=1.6 mm, N=1.9 mm, M=2.5 mm |
| (8) Temperature characteristic | B5=X5R, B7=X7R, C6=X6S, C7=X7S, D7=X7T, CG/C0G, CH, CJ, CK |
| (9) Capacitance | 3-digit code, R = decimal point |
| (10) Tolerance | K=±10%, M=±20%, etc. |
| (11) Packaging | F, R, T, P |

## Key Electrical/Test Requirements
- Operating temperature range: -55°C to +125°C for Class 1; Class 2 depends on dielectric.
- Storage: ≤30°C, ≤70% RH recommended; use within 6 months of delivery.
- Rated voltage: 4 V to 630 V depending on series.
- Withstanding voltage: Class 1 = 3× rated (or 2× for high-frequency type); Class 2 = 2.5× rated.
- Insulation resistance: Class 1 ≥10,000 MΩ; Class 2 ≥10,000 MΩ for C≤0.047 µF, or 500 MΩ·µF for C>0.047 µF.
- Capacitance tolerance: Class 1 ±0.25 pF, ±0.5 pF, ±5%; Class 2 ±10%, ±20%.
- Q/DF: Class 1 Q≥400+20C (C<30 pF), Q≥1000 (C≥30 pF); Class 2 DF ≤2.5% typical.
- Endurance, temperature cycling, humidity, soldering heat, vibration, mechanical shock, board flex tested per AEC-Q200 and IEC standards.
