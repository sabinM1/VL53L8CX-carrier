# Yageo AC Series — AEC-Q200 Chip Resistors

Source file: `PYu-AC_51_RoHS_L_11.pdf`

## Scope
AC0201 to AC2512 chip resistors with lead-free terminations, thick-film process.

## Applications
- All general-purpose applications
- Car electronics
- Industrial applications

## Features
- AEC-Q200 qualified
- MSL 1
- Soldering compliant with J-STD-020D
- Halogen-free epoxy
- RoHS compliant
- Pb-glass exempted by RoHS
- High component and equipment reliability
- 100% automatic optical inspection before taping

## Ordering Information — Global Part Number
Format:
`AC XXXX X X X X XXXX L`

| Field | Meaning |
|---|---|
| (1) Size | 0201/0402/0603/0805/1206/1210/1218/2010/2512 |
| (2) Tolerance | B=±0.1% low TCR; D=±0.5%; F=±1%; J=±5% |
| (3) Packaging | R=paper taping reel; K=embossed taping reel |
| (4) TCR | E=±50 ppm/°C |
| (5) Reel | 07=7-in standard; 7W=7-in 2× power; 13=13-in; 3W=13-in 2× power |
| (6) Resistance | 1 Ω–22 MΩ; R/K/M = decimal point |
| (7) Default | B = bulk AOI ordering only |

Example: `AC0402FR-07100KL` = AC0402, ±1%, 7-in reel, 100 kΩ.

## Marking
- AC0201/0402: no marking
- AC0603/0805/1206/1210/2010/2512:
  - E-24 ±5%: 3 digits
  - E-96 ±1%, ±0.5%: E-96 marking
- AC0805/1206/1210/2010/2512:
  - ±1%, ±0.5%: 4 digits
- AC1218:
  - E-24 ±5%: 3 digits
  - ±1%, ±0.5%: 4 digits

## Construction
Automotive-grade ceramic body, internal metal electrodes, resistive glaze, protective glass, laser trimming, protective overcoat, Ni/matte tin terminations.
