# Yageo RE Series — Precision-Grade Thick-Film Chip Resistors

Source file: `pyu-re_105_rohs_l.pdf`

## Scope
RE0201 to RE1206 ultra-precision chip resistors with lead-free terminations, thick-film process.

## Applications
- Converters
- Printer equipment
- Server boards
- Telecom
- Consumer

## Features
- Halogen-free epoxy
- RoHS compliant
- High component and equipment reliability
- Non-forbidden materials
- MSL 1

## Ordering Information — Global Part Number
Format:
`RE XXXX X X XXXX L`

| Field | Meaning |
|---|---|
| (1) Size | 0201/0402/0603/0805/1206 |
| (2) Tolerance | B=±0.1%, D=±0.5%, F=±1% |
| (3) Packaging | R = paper/PE taping reel |
| (4) TCR | E = ±50 ppm/°C |
| (5) Reel | 07=7-in, 10=10-in, 13=13-in |
| (6) Resistance | 2–4 digits; R/K/M = decimal point |
| (7) Default | L |

Example: `RE0603DRE0756RL` = RE0603, ±0.5%, TC50, 56 Ω, 7-in reel.

## Marking
- RE0201/0402: no marking
- RE0603:
  - 1%, 0.5%, 0.1% E24 exception values: 3 digits
  - E96: EIA-96 marking
- RE0805/1206: 4 digits (E24 or E96)

## Construction
High-grade ceramic body, internal metal electrodes, resistive layer, laser trimming, protective coat, matte tin terminations.
