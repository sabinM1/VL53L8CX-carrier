# Round-10 review package — VL53L8CX × 5 carrier on Teensy 4.0 (Rev 6)

This message is self-contained. No files are attached — the upload channel is
closed, so the current sources are embedded verbatim below. Review what is here,
not an imagined repository. Where something is not embedded, it is labelled
"not included" with a one-line description.

The firmware below is the exact text that compiles.

================================================================================
1. PROJECT
================================================================================

Five identical carrier boards, each with one ST VL53L8CX 8x8 multizone ToF
sensor, on a Teensy 4.0 (i.MX RT1062, 600 MHz, 3.3 V I/O, not 5 V tolerant).
The sensors run from a separate external 3.3 V rail; the Teensy's 3.3 V pin
(~250 mA) is not used by them. The PCB/schematic is not drawn. This is a
pre-layout design review plus a firmware review.

--- 1.1 Carrier (per board, 20 SMD parts) -------------------------------------

J1 (1x6): 3V3_EXT | GND | SCLK | MOSI | MISO | NCS
   |
   +-- 3V3 --> U2 MIC5504-1.8 (EN = IN, 25 R auto-discharge) --> 1V8
   |            C6 2.2uF in, C7 1uF out
   +-- SCLK/MOSI/MISO --> U3 SN74AXC4T774 (VCCA 1.8 / VCCB 3.3), OE = NCS_S
   +-- NCS --> U5 SN74AXC1T45 (DIR = GND, B->A: host drives sensor),
   |           A = NCS_S, B = NCS_H
   |
   +-- VL53L8CX (SPI mode; AVDD 3.3, CORE_1V8 + IOVDD 1.8)

- The OE->NCS_S scheme is the core of the design. U3's OE is driven by that
  board's own NCS_S, and NCS_S is produced by U5, NOT by U3. NCS low => board
  selected => U3 enabled => its MISO drives the shared bus. NCS high => U3
  Hi-Z => MISO released. Routing NCS through U3 deadlocks (the board can never
  be selected); that was the Rev-1 defect.
- R6 = 6.8 kOhm, SCLK_S -> 1V8. U3 has 71 kOhm typical static pull-downs on its
  data I/Os (SCES898C 7.3.9) [V], so SCLK_S idles at 1.8 x 71/77.8 = 1.64 V
  when U3 is disabled, above the sensor's V_IH (0.7 x 1.8 = 1.26 V). Without it
  the first host-driven SCLK edge at selection could be sampled as a clock.
- R7 = 4.7 kOhm, NCS_H -> 3V3. Holds the board deselected while the host GPIO
  is a reset input.
- R1-R5 = 47 kOhm to IOVDD on NCS_S, INT, SYNC, LPn, SPI_I2C_N (DS14161 Table 3
  [V]). C1 = 4.7 uF at AVDD, C2/C3/C4/C5/C8/C9 = 100 nF.
- Known-good numbers (DS14161 Rev 7): SPI <= 3 MHz, mode 3, NCS-to-clock >= 0 ns;
  I2C <= 1 MHz; AVDD 3.13-3.47 V; IOVDD/CORE_1V8 1.62-1.98 V; slew minimums
  0.012 V/us on CORE_1V8/IOVDD (0.9->1.6 V <= 58.3 us) and 0.001 V/us on AVDD;
  active ranging 43/50 mA AVDD + 50/80 mA CORE_1V8, +10 mA peak each; V_IH >=
  0.7 x IOVDD, V_OL <= 0.2 x IOVDD at 4 mA.

--- 1.2 System power (Rev 6 decision) -----------------------------------------

- One load switch on 3V3_EXT (TPS22918-class, >= 1.5 A), CT open => t_R ~ 95 us
  at 3.3 V, i.e. ~0.0278 V/us, 2.3x the DS14161 minimum slew.
- ON pin: 100 kOhm to GND (rail defaults off), driven by Teensy pin 2.
- 22 uF at the switch VIN (IR-drop reservoir: ~0.43 Ohm round trip of 28 AWG x
  750 mA ~ 0.32 V of far-end sag), 1 uF at VOUT, >= 47 uF bulk upstream.
- 36.5 uF downstream (5 x 7.1 uF + 1 uF at VOUT) => inrush ~ 1.27 A into a 2 A switch.
- The switch is also the sensor reset and the only stuck-I2C recovery path:
  pulling the LDO's EN low would auto-discharge only 1.8 V while AVDD stayed at
  3.3 V, which DS14161 forbids (all three supplies must come down together).
- Rail load: 465 mA typ / 750 mA peak; <= 59 mV drop in the switch.

--- 1.3 Teensy 4.0 pin map (core 1.62.0, verified) ----------------------------

Bus              Object   SCK/SDA  MOSI  MISO/SCL  CS   Location
SPI (LPSPI4)     SPI      13       11    12        10   header
SPI1 (LPSPI3)    SPI1     27       26    1         0    SCK/MOSI bottom pads
SPI2 (LPSPI1)    SPI2     37       35    34        36   bottom pads
Wire (LPI2C1)    Wire     19       18    -         -    header
Wire1 (LPI2C3)   Wire1    16       17    -         -    header

Only pins 0-23 are breadboardable. Pin 13 drives the on-board LED and SCK idles
high in mode 3; CNT_SCK_PINS = 1 for every T4.0 SPIClass, so setSCK() cannot
remap it. Pins 0/1 are Serial1; 16/17 are Serial4. BUFFER_LENGTH 136, tx 137.
Pin 2 is used only for the rail enable.

2. FIRMWARE - MODE A (production topology), verbatim
================================================================================

~~~cpp
// mode_a_single_bus.ino - Teensy 4.0
// MODE A: all five sensors on ONE SPI bus, one CS per sensor, polled
// sequentially. SPI (LPSPI4): SCK=13, MOSI=11, MISO=12. CS = 10,9,8,7,6.
// Serial: USB CDC @ 115200. CSV: ms,S0..S4 (-1 = no fresh valid target).
#include <Arduino.h>
#include <SPI.h>
#include <vl53l8cx.h>

#ifndef VL53L8CX_CS_SETTLE_US
#error "Unpatched VL53L8CX library: CS-settle delay missing."
#endif
#if !defined(VL53L8CX_COMMS_CHUNK_SIZE) || VL53L8CX_COMMS_CHUNK_SIZE > 1024
#error "VL53L8CX chunk-size override missing: copy vl53l8cx_platform_config_custom.h"
#endif
#if !defined(VL53L8CX_DISABLE_AMBIENT_PER_SPAD) || !defined(VL53L8CX_DISABLE_SIGNAL_PER_SPAD) \
 || !defined(VL53L8CX_DISABLE_MOTION_INDICATOR)
#error "Output trimming missing: the patched platform_config_custom.h is not being used"
#endif
static_assert(sizeof(VL53L8CX_ResultsData) <= 512,
              "ResultsData should be the trimmed layout (~258 bytes)");

static const uint8_t PIN_SCK  = 13;
static const uint8_t PIN_MOSI = 11;
static const uint8_t PIN_MISO = 12;

static const uint8_t NUM_SENSORS = 5;
static const uint8_t NCS_PINS[NUM_SENSORS] = {10, 9, 8, 7, 6};

// The external 3V3_EXT rail sits behind a host-controlled load switch whose ON
// pin has a 100k pull-down, so the rail is OFF whenever the Teensy is reset or
// unpowered. Must be raised before any bus pin is driven.
static const uint8_t RAIL_EN_PIN = 2;

static const uint32_t SENSOR_SPI_HZ = 3000000UL;
static const uint8_t  RANGING_HZ    = 15;
static const uint8_t  CENTER_ZONE   = 27;
static const uint8_t  MAX_CONSEC_ERRORS = 50;
static const uint32_t RETRY_PERIOD_MS   = 30000;
static const uint8_t  SILENT_BACKOFF_AFTER = 3;    // consecutive silent demotions
static const uint32_t SILENT_BACKOFF_MULT  = 10;   // 30 s -> 300 s cap
static const uint16_t FRAME_PERIOD_MS   = 1000 / RANGING_HZ;
static const uint32_t STALE_MS          = 3UL * FRAME_PERIOD_MS;

static const uint32_t NO_FRAME_TIMEOUT_MS =
  (5UL * FRAME_PERIOD_MS > 2000UL) ? (5UL * FRAME_PERIOD_MS) : 2000UL;

static inline bool status_ok(uint8_t s) { return s == 5 || s == 9; }

static VL53L8CX s0(&SPI, NCS_PINS[0], -1, -1, SENSOR_SPI_HZ);
static VL53L8CX s1(&SPI, NCS_PINS[1], -1, -1, SENSOR_SPI_HZ);
static VL53L8CX s2(&SPI, NCS_PINS[2], -1, -1, SENSOR_SPI_HZ);
static VL53L8CX s3(&SPI, NCS_PINS[3], -1, -1, SENSOR_SPI_HZ);
static VL53L8CX s4(&SPI, NCS_PINS[4], -1, -1, SENSOR_SPI_HZ);

static VL53L8CX *const sensors[NUM_SENSORS] = {&s0, &s1, &s2, &s3, &s4};

static bool     sensor_ok[NUM_SENSORS]     = {false};
static uint8_t  consec_errors[NUM_SENSORS] = {0};
static uint8_t  silent_fails[NUM_SENSORS]  = {0};
static int16_t  last_mm[NUM_SENSORS];
static uint32_t last_update_ms[NUM_SENSORS];
static uint32_t last_retry_ms[NUM_SENSORS];
static VL53L8CX_ResultsData results;       // reused, trimmed layout

static void park_all_ncs_high() {
  for (uint8_t i = 0; i < NUM_SENSORS; i++) {
    pinMode(NCS_PINS[i], OUTPUT);
    digitalWrite(NCS_PINS[i], HIGH);
  }
}

static bool configure(uint8_t i) {
  uint8_t st = sensors[i]->init();
  if (st != VL53L8CX_STATUS_OK) { Serial.printf("# S%u init FAILED (%u)\n", i, st); return false; }
  st = sensors[i]->set_resolution(VL53L8CX_RESOLUTION_8X8);
  if (st != VL53L8CX_STATUS_OK) { Serial.printf("# S%u set_resolution FAILED (%u)\n", i, st); return false; }
  st = sensors[i]->set_ranging_frequency_hz(RANGING_HZ);
  if (st != VL53L8CX_STATUS_OK) { Serial.printf("# S%u set_frequency FAILED (%u)\n", i, st); return false; }
  st = sensors[i]->set_ranging_mode(VL53L8CX_RANGING_MODE_CONTINUOUS);
  if (st != VL53L8CX_STATUS_OK) { Serial.printf("# S%u set_mode FAILED (%u)\n", i, st); return false; }
  return true;
}

static bool start(uint8_t i) {
  uint8_t st = sensors[i]->start_ranging();
  if (st != VL53L8CX_STATUS_OK) { Serial.printf("# S%u start_ranging FAILED (%u)\n", i, st); return false; }
  return true;
}

static void demote(uint8_t i) {
  sensor_ok[i] = false;
  consec_errors[i] = 0;
  last_mm[i] = -1;
  last_retry_ms[i] = millis();
  // stop_ranging() is never called anywhere in this sketch. A demoted sensor
  // may be dead, and stop_ranging() polls its MCU-stop bit for ~5 s; init()
  // starts with a software reboot, so bring_up() does not need it stopped.
}

static bool probe(uint8_t i) {
  for (uint8_t a = 0; a < 3; a++) {
    uint8_t alive = 0;
    if (sensors[i]->is_alive(&alive) == VL53L8CX_STATUS_OK && alive) return true;
    delay(50);   // the sensor may still be coming out of reset
  }
  return false;
}

static bool bring_up(uint8_t i) {
  if (!probe(i)) {
    Serial.printf("# S%u is_alive FAILED\n", i);
    return false;
  }
  // One attempt only: the retry loop is the retry mechanism, and every extra
  // attempt here blocks polling for all healthy sensors.
  if (configure(i) && start(i)) {
    consec_errors[i] = 0;
    last_update_ms[i] = millis();
    return true;
  }
  return false;
}

static void bring_up_all() {
  for (uint8_t i = 0; i < NUM_SENSORS; i++) {
    sensor_ok[i] = false;
    if (!probe(i)) {
      Serial.printf("# S%u not responding at boot\n", i);
      continue;
    }
    for (uint8_t a = 0; a < 3 && !sensor_ok[i]; a++) {
      sensor_ok[i] = configure(i);
      if (!sensor_ok[i]) delay(50);
    }
  }
  for (uint8_t i = 0; i < NUM_SENSORS; i++) {
    if (sensor_ok[i]) {
      sensor_ok[i] = start(i);
      if (sensor_ok[i]) {
        last_update_ms[i] = millis();
        Serial.printf("# S%u ranging at %u Hz\n", i, RANGING_HZ);
      }
    }
  }
}

void setup() {
  // Raise the external rail first. While the switch is off, driving any NCS
  // high pushes ~0.7 mA through that board's R7 into a dead 3V3 node.
  pinMode(RAIL_EN_PIN, OUTPUT);
  digitalWrite(RAIL_EN_PIN, HIGH);
  delay(5);                        // switch t_R ~95 us + LDO turn-on

  park_all_ncs_high();

  Serial.begin(115200);
  uint32_t t0 = millis();
  while (!Serial && (millis() - t0) < 3000) {}

  for (uint8_t i = 0; i < NUM_SENSORS; i++) {
    last_mm[i] = -1;
    last_update_ms[i] = 0;
    last_retry_ms[i] = 0;
  }

  Serial.println("# VL53L8CX MODE A: single SPI bus (header pins), sequential");

  SPI.begin();
  for (uint8_t i = 0; i < NUM_SENSORS; i++) {
    sensors[i]->begin();
  }
  bring_up_all();

  Serial.println("# ms,S0,S1,S2,S3,S4");
}

void loop() {
  bool updated_any = false;

  for (uint8_t i = 0; i < NUM_SENSORS; i++) {
    if (!sensor_ok[i]) continue;

    uint8_t ready = 0;
    uint8_t st = sensors[i]->check_data_ready(&ready);
    if (st != VL53L8CX_STATUS_OK) {
      if (++consec_errors[i] >= MAX_CONSEC_ERRORS) {
        Serial.printf("# S%u demoted after %u errors\n", i, consec_errors[i]);
        demote(i);
      }
      continue;
    }
    if (!ready) continue;

    if (sensors[i]->get_ranging_data(&results) != VL53L8CX_STATUS_OK) {
      if (++consec_errors[i] >= MAX_CONSEC_ERRORS) {
        Serial.printf("# S%u demoted after %u errors\n", i, consec_errors[i]);
        demote(i);
      }
      continue;
    }

    consec_errors[i] = 0;
    silent_fails[i] = 0;
    const uint8_t z = CENTER_ZONE * VL53L8CX_NB_TARGET_PER_ZONE;
    uint8_t tgt = results.nb_target_detected[CENTER_ZONE];
    uint8_t stt = results.target_status[z];
    last_mm[i] = (tgt > 0 && status_ok(stt)) ? results.distance_mm[z] : -1;
    last_update_ms[i] = millis();
    updated_any = true;
  }

  if (updated_any) {
    uint32_t now = millis();
    Serial.printf("%lu", (unsigned long)now);
    for (uint8_t i = 0; i < NUM_SENSORS; i++) {
      bool fresh = sensor_ok[i] && (now - last_update_ms[i] <= STALE_MS);
      Serial.printf(",%d", fresh ? (int)last_mm[i] : -1);
    }
    Serial.println();
  }

  // Retry one dead sensor per pass. Runs BEFORE the no-frame check because
  // bring_up() blocks the loop for up to ~2 s.
  bool did_retry = false;
  for (uint8_t i = 0; i < NUM_SENSORS; i++) {
    uint32_t period = (silent_fails[i] >= SILENT_BACKOFF_AFTER)
                        ? RETRY_PERIOD_MS * SILENT_BACKOFF_MULT
                        : RETRY_PERIOD_MS;
    if (!sensor_ok[i] && (millis() - last_retry_ms[i] >= period)) {
      last_retry_ms[i] = millis();
      Serial.printf("# retry S%u\n", i);
      sensor_ok[i] = bring_up(i);
      did_retry = true;
      break;
    }
  }

  if (did_retry) {
    // Re-baseline every healthy sensor: a blocking bring_up() is not their
    // fault, and without this one wedged sensor blanks the whole array.
    uint32_t t = millis();
    for (uint8_t i = 0; i < NUM_SENSORS; i++) {
      if (sensor_ok[i]) last_update_ms[i] = t;
    }
  } else {
    // No-frame timeout: demote a sensor that stops delivering frames even
    // though its reads keep returning OK (the SPI path cannot report an error).
    // Three consecutive silent demotions cost real array duty on every retry,
    // so back the retry period off x10 (capped) until a frame arrives again.
    uint32_t now_ms = millis();
    for (uint8_t i = 0; i < NUM_SENSORS; i++) {
      if (sensor_ok[i] && (now_ms - last_update_ms[i] > NO_FRAME_TIMEOUT_MS)) {
        if (silent_fails[i] < SILENT_BACKOFF_AFTER &&
            ++silent_fails[i] == SILENT_BACKOFF_AFTER) {
          Serial.printf("# S%u silent %ux -> retry period %lu ms\n", i,
                        SILENT_BACKOFF_AFTER,
                        (unsigned long)(RETRY_PERIOD_MS * SILENT_BACKOFF_MULT));
        }
        Serial.printf("# S%u no frame for %lu ms -> demoted\n", i,
                      (unsigned long)(now_ms - last_update_ms[i]));
        demote(i);
      }
    }
  }

  delay(2);
}
~~~

--- 3.2 IO_Read - I2C path (patched) -----------------------------------------

~~~cpp
if (dev_i2c) {
  int status = 0;
  uint8_t buffer[2];
  // LOCAL PATCH: bounded retry (stock code loops forever on a NACK).
  for (uint8_t attempt = 0; ; attempt++) {
    dev_i2c->beginTransmission((uint8_t)((_dev.platform.address >> 1) & 0x7F));
    buffer[0] = (uint8_t)(RegisterAddress >> 8);
    buffer[1] = (uint8_t)(RegisterAddress & 0xFF);
    dev_i2c->write(buffer, 2);
    status = dev_i2c->endTransmission(false);
    if (status == 0) break;
#ifdef ARDUINO_ARCH_STM32
    if (status) { dev_i2c->end(); dev_i2c->begin(); }
#endif
    if (attempt + 1 >= VL53L8CX_I2C_NACK_RETRIES) return 1;
    delayMicroseconds(100);
  }
  uint32_t i = 0;
  if (size > DEFAULT_I2C_BUFFER_LEN) {
    while (i < size) {
      uint8_t current_read_size = (size - i > DEFAULT_I2C_BUFFER_LEN
                                     ? DEFAULT_I2C_BUFFER_LEN : size - i);
      // LOCAL PATCH: a zero-length requestFrom means the address phase NACKed,
      // so the sensor's pointer did not advance and the chunk is replayable.
      // A short (partial) chunk cannot be replayed: the pointer moved.
      uint8_t got = 0;
      for (uint8_t chunk_attempt = 0; ; chunk_attempt++) {
        got = (uint8_t)dev_i2c->requestFrom(
                ((uint8_t)((_dev.platform.address >> 1) & 0x7F)), current_read_size);
        if (got != 0) break;
        if (chunk_attempt + 1 >= VL53L8CX_I2C_NACK_RETRIES) return 1;
        delayMicroseconds(100);
      }
      while (dev_i2c->available()) { p_values[i] = dev_i2c->read(); i++; }
      if (got != current_read_size) return 1;
    }
  } else {
    if (dev_i2c->requestFrom(((uint8_t)((_dev.platform.address >> 1) & 0x7F)), size) == 0)
      return 1;
    while (dev_i2c->available()) { p_values[i] = dev_i2c->read(); i++; }
  }
  return i != size;
}
~~~

~~~cpp
if (dev_spi) {
  uint32_t position = 0, data_size = 0;
  uint16_t temp;
  // LOCAL PATCH: IO_Read sends only the 2-byte command header, so a full
  // chunk-sized buffer would waste ~1 KB of stack for nothing.
  uint8_t data_write[2];
  for (position = 0; position < size; position += VL53L8CX_COMMS_CHUNK_SIZE) {
    ...
    data_write[0] = SPI_READ_MASK(temp) >> 8;
    data_write[1] = SPI_READ_MASK(temp) & 0xFF;
    dev_spi->beginTransaction(SPISettings(spi_speed, MSBFIRST, SPI_MODE3));
    digitalWrite(cs_pin, LOW);
    // LOCAL PATCH: let U5/U3 enable before the first SCLK edge.
    delayMicroseconds(VL53L8CX_CS_SETTLE_US);
    dev_spi->transfer(&data_write, 2);
~~~

================================================================================
5. QUESTIONS
================================================================================

1. Rail-enable ordering. pinMode(2, OUTPUT); digitalWrite(2, HIGH); delay(5);
   then park NCS. Is 5 ms enough for the switch + LDOs at 36.5 uF, or should the
   first is_alive() probe (3 x 50 ms) be the only delay? Is pin 2 a safe choice
   on a Teensy 4.0 (no bus, no PWM collision that matters)?

2. Back-off correctness. silent_fails[] increments only on the no-frame
   demotion, so a sensor demoted through consec_errors (it answers, but with
   errors) never backs off and keeps a 30 s cadence. Is that the right split, or
   should repeated error-demotions also back off? Also: the counter is reset on
   every successful frame, which means a flapping sensor never reaches 3 -
   intended.

3. Retry vs no-frame ordering. The retry runs first; if it ran, the no-frame
   check is skipped entirely and every healthy sensor is re-baselined. Two dead
   sensors therefore delay each other's detection by one pass. Any scenario
   where that hides a third failing sensor indefinitely?

4. Library patch. Read 3.2-3.3 as source. Is the zero-length-chunk retry
   correct with respect to the sensor's auto-increment pointer? Is anything
   still unbounded on the I2C write path (IO_Write ignores intermediate
   endTransmission results; the firmware checksum is the only backstop)?

5. Power. One TPS22918-class switch, 22 uF at VIN, >= 47 uF upstream, 100 kOhm
   on ON, 36.5 uF downstream. Anything materially wrong before layout?

6. Anything in the embedded firmware that is now inconsistent with itself
   after the Rev-6 edits.
